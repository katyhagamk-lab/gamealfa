Один квартал в банке — учебная игра

Как залить на сервер:
1. Загрузите файл index.html в корень сайта (или в любую папку).
2. Откройте адрес сайта в браузере — игра запустится сама.

Один файл подходит и для телефона, и для ноутбука:
вёрстка сама подстраивается под ширину экрана.
На телефоне офис крупнее, если повернуть экран горизонтально.

Прогресс сохраняется в браузере игрока (localStorage):
после перезагрузки игра продолжается с того же места.
Начать заново: Карта → «Начать заново».

Шрифты подгружаются с Google Fonts. Без интернета игра работает,
но со стандартными шрифтами.
